# ADR-003:密码仅存 Windows Credential Manager

日期:2026-07-20 · 状态:已接受

## 背景

启动其他用户的进程必须提供其 Windows 密码;密码持久化方案必须满足“配置文件零明文”。

## 备选方案

1. **DPAPI 自行加密后存 config.json**:可行,但自造轮子,且密文仍随配置文件被导出/同步。
2. **每次启动手动输入**:安全但违背“一键启动”目标。
3. **Windows Credential Manager(CredWriteW/CredReadW)**:系统级加密存储,随用户账户保护,凭据与配置天然分离。

## 决策

选方案 3。凭据键 `BPM_<用户名>`,类型 GENERIC,持久化 LOCAL_MACHINE;config.json 只保存凭据键。

## 结果

- 配置导入/导出天然不含密码(导入后需重新录入密码,UI 已提示)。
- 删除配置档时,若凭据不再被其他配置档共用则一并删除。
- 密码明文仅在启动瞬间存在于进程内存;日志全程不落敏感信息。
