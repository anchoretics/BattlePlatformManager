BPM v1.1.0 改善独立 Windows 用户的战网首次登录流程，并加入自动管理员启动、单实例和新的应用图标。

### 新增与改进

- 浏览器登录辅助：无需先登录目标用户的 Windows 桌面；战网发起网页认证时，自动用同一 Windows 用户的 Edge 或机器级 Chrome 打开真实登录页面。
- 每个配置可独立开关辅助，并查看状态、重试或打开“手动登录一次”指引。辅助不可用时仍可启动战网。
- BPM 首次启动自动请求管理员权限；重复启动恢复已有窗口，同一用户和会话只运行一个管理器。快捷方式请求会转交已有实例。
- 更新应用图标与操作图标，改善窗口缩放、小屏幕滚动及账号编辑界面。
- 提供“仅初始化已有本地用户”恢复入口，继续未完成的账号设置。

### 修复

- 修复创建系统账号时用户配置初始化报错 `0x800706F7`。
- 修复删除确认期间选中项变化造成误删其他配置和凭据。
- 修复助手缓存通过硬链接改写缓存外文件或权限。
- 拒绝结构无效的配置；无效导入保留原配置。
- 刷新列表保留启动中的状态；同一配置的并发启动请求共用一次启动。

### 下载与升级

下载 `BPM-v1.1.0-win-x64.zip`，解压后运行 `BPM.exe`。该包适用于 Windows 10/11 x64，包含 .NET 运行时，无需另行安装 .NET。

升级前完全退出旧 BPM，再使用新版。配置继续保存在 `%AppData%\BPM\config.json`，Windows 密码仍保存在凭据管理器中；压缩包不包含用户配置、密码或认证链接。

浏览器认证和短信验证仍由用户本人完成。浏览器辅助已在本机 wow2/wow3 验证；不同 Windows 或战网版本可能需要使用界面内的手动登录指引。已有快捷方式若带有旧管理员运行标记，可在新版中重新创建，以避免重复启动时由 Windows 提前显示 UAC。

校验文件 `BPM-v1.1.0-win-x64.zip.sha256` 提供压缩包 SHA-256。发布前完整自动化 188 项通过，Debug/Release 构建均为 0 警告、0 错误。
